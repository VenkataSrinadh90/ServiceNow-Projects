# ServiceNow-Projects
# Student Leave Management System 🧑‍🎓
# Project Overview 💭
The Student Leave Management System is a ServiceNow-based application designed to simplify and automate the leave request process within an educational institution. The system enables students to submit leave requests, faculty members to review and approve/reject requests, and administrators to manage users and generate reports.
# Problem Statement ❓

Develop a leave management system where:

* Students can submit leave requests.
* Students can track the status of their leave applications.
* Faculty members can approve or reject leave requests.
* Administrators can manage users and access reports.
* Role-based access control ensures secure and appropriate access to system features.

# Technologies & Concepts Used ⚙️
* ServiceNow Platform
* Tables
* Users
* Roles
* Application Menus
* Modules
* Access Control Lists (ACLs)

# Project Workflow 🪜
1. Student logs into the system.
2. Student submits a leave request.
3. Leave status is automatically set to Requested.
4. Faculty reviews pending requests.
5. Faculty approves or rejects the request.
6. Faculty adds comments if necessary.
7. Student checks updated leave status through My Leaves.
8. Administrator monitors all requests and generates reports.

# Expected Outcome

After completing this project, users will gain:

* Understanding of ServiceNow Tables
* Knowledge of User and Role Management
* Experience with Application Menus and Modules
* Practical implementation of ACLs
* Understanding of Role-Based Access Control (RBAC)
* Experience in building a real-world ServiceNow application
